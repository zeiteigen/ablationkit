# create-run-panel

A run inspector tab and a project panel that read runs through the bridge.

```sh
ablationkit extension scaffold --template create-run-panel --id my-create-run-panel
ablationkit extension validate --path .ablationkit/extensions/my-create-run-panel
```

Then build, review and approve it in Project settings → Extensions (an agent builds it with the `ablationkit_do extension.build` tool of `ablationkit mcp`).
